## Getting Started

You must have RUST installed in your system in order to run this project.

## Prerequisites

Make sure you have the following installed:

- **RUST**

  Install GO from:

  ```sh
  https://rust-lang.org/tools/install/
  ```

  ⚠️ **Supported GO version:** `0.2`



## Installation

1. **Clone the repository**

2. **Navigate to the project directory**

3. **Install dependencies**

```sh
cargo build
```
### To start the server

```sh
cargo run
```

Wasmer enables super lightweight containers based on WebAssembly that can run anywhere.
